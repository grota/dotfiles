# Stale-by-name sources

Companion to the bundled `grounded-citations` skill, which is upstream-owned and
must not be edited locally. Load both when a citation involves a live figure.

## When to Use

Quoting a figure that has an expiry: opening hours, public-office schedules,
transport timetables, prices, benefit or vaccination eligibility, anything tied to
a season or campaign. Load alongside `grounded-citations` for citation work.

## The trap

**Treating a page about the same named place or service as current because of the
name.** Press round-ups of opening hours, schedules, prices and eligibility keep
ranking for years while the name they describe never changes.

Before quoting any figure:

1. Read the byline / "last updated" date.
2. Identify which season, campaign or tariff cycle the table belongs to.
3. Say which cycle it describes — or don't quote it.

Applies to: health-centre and pharmacy hours, public-office schedules, transport
timetables, ticket prices, subsidy/benefit eligibility, anything with a campaign
name. A current-looking page about an unchanged name is the default failure mode.
